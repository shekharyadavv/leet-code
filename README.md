# leet-code

Solutions to LeetCode problems in C++ and Python. Each problem lives in its own
subdirectory named after the question, containing both a `.cpp` and a `.py`
solution with the approach explained in comments.

## Problems

| # | Title | Difficulty | Link |
|---|-------|------------|------|
| 18 | [4Sum](18_4sum/) | Medium | https://leetcode.com/problems/4sum/ |
| 23 | [Merge k Sorted Lists](23_merge_k_sorted_lists/) | Hard | https://leetcode.com/problems/merge-k-sorted-lists/ |
| 24 | [Swap Nodes in Pairs](24_swap_nodes_in_pairs/) | Medium | https://leetcode.com/problems/swap-nodes-in-pairs/ |

## Structure

```
<question_id>_<slug>/
  <question_id>_solution.cpp
  <question_id>_solution.py
```
